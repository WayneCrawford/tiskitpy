**************************************************************
Avoiding earthquakes and other noisy data
**************************************************************

.. py:module:: tiskitpy

All of the class constructors that use time series data can remove unwanted
time spans, including the noisy time after large earthquakes.

The constructors are :py:meth:`SpectralDensity.from_stream() <tiskitpy.SpectralDensity.from_stream>`, 
:py:meth:`DataCleaner() <tiskitpy.DataCleaner>` and :py:meth:`CleanRotator() <tiskitpy.CleanRotator>`.
They share the following input parameters:

- ``avoid_spans`` (:py:class:`TimeSpans <tiskitpy.TimeSpans>`)
- ```remove_eqs``` (``str`` or ``bool``)

and provide the following properties:

- ``avoided_spans```: time spans NOT used in processing
- ``used_spans```: inverse of ``avoided_spans``

By default ``remove_eqs=True`` for all of the constructors, meaning that they
will run :py:meth:`TimeSpans.from_eqs() <tiskitpy.TimeSpans.from_eqs>` to generate time spans to avoid based
on the USGS earthquake catalog (online or saved in a file by a previous call
to :py:meth:`TimeSpans.from_eqs`).  If the user sets ``remove_eqs`` to a string, this must
correspond to the name of a local file in QuakeML format.

``avoid_spans`` can be used to specify other time spans to avoid.  The software
will merge these time spans with any generated by ``remove_eqs``.  The
merged list of time spans avoided is provided in the object's ``avoided_spans``
property.

The :py:meth:`SpectralDensity.from_stream` constructor also has a parameter called ``z_threshold``,
used to eliminate outliers in the calculated spectra.  ``avoided_spans``
includes these time spans.

Using time spans
==================

If you call :py:meth:`SpectralDensity.from_stream`, :py:meth:`DataCleaner`, and :py:meth:`CleanRotator`
with their default parameters, they will all remove time spans based on global
earthquakes stored in the USGS database, using the default parameters
in :py:meth:`TimeSpans.from_eqs`.  :py:meth:`SpectralDensity.from_stream` provides an additional culling
based on spectral density outliers.

If you want all of the classes to avoid the same time spans,
you can use the ``avoided_spans`` property of the SpectralDensity
object as input to `DataCleaner` and `CleanRotator`'s ``avoid_spans``
parameters.  You can set their ``remove_eqs`` parameter to ``False``, since the
``avoided_spans`` property will already contain the earthquake-based spans.

If you want to use another earthquake catalog than USGS's, or other parameters
for how much time to avoid after an earthquake, you can run
:py:meth:`TimeSpans.from_eqs()` with your own parameters or you can run your own code.
In the latter case, you will need to convert your output to a :py:class:`TimeSpans` object.
You can then set into the constructor's ``avoid_spans``
parameter to this object (and set ``remove_eqs=False``)
